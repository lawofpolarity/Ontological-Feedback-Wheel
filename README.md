# Ontological Feedback Wheel

> **Legacy LightMathematics dynamical-model candidate. Historical language preserved; anthropomorphic claims are not inherited.**

The 2025 source proposed a recursive "identity" update with twelve surrounding roles. Its original README is preserved unchanged at [docs/LEGACY_ONTOLOGICAL_FEEDBACK_SOURCE.md](docs/LEGACY_ONTOLOGICAL_FEEDBACK_SOURCE.md).

The recoverable mathematical core is a discrete state-update model:

[
I_{n+1}=I_n+Delta r_n,w_n
]

where (I_n) is interpreted here as a **model state vector or scalar state**, not personal identity; (Delta r_n) is a declared feedback/error/coherence change, not automatically canonical RSCS; and (w_n) is a declared update weight.

## Important correction

The historical equation does not by itself create self-awareness, beliefs or self-knowledge. It describes a feedback-dependent state update once its variables are operationally defined.

Likewise,

[
lim_{n	oinfty}I_n=I^*
]

is a **convergence hypothesis**, not a consequence of the update equation. Stability requires conditions on the update sequence.
